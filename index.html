How to Create 30-Second Videos in Two Parts

        
Most tools generate 15 seconds at a time. Every 30-second prompt here is written so it splits cleanly.

        
    
          
  1. Generate Part 1 using Scenes 1–3 of the prompt.
    2. 
          
  2. Use the last frame of Part 1 as the starting image for Part 2.
    3. 
          
  3. Paste Scenes 4–6 and keep the same character lock line word-for-word.
    4. 
          
  4. Join both parts in any editor — the ending is written to loop back to the hook.

        Consistency
        
Keeping the Same Character in Every Scene

        
Character drift is the #1 reason AI series fail. These rules fix it.

        
    
          
  1. Never rewrite the CHARACTER & STYLE LOCK block between scenes or episodes.
    2. 
          
  2. Reuse one reference image of your character in image-to-video mode.
    3. 
          
  3. If the face changes, regenerate that scene only — never accept a drifted scene.
    4. 
          
  4. Keep the same outfit colours named in the lock for the whole series.
    5.

Posting Checklist for Reels, Shorts & TikTok

        
The video is only half the work — package it the way the prompt was designed for.

        
    
          
  1. Use the on-screen hook text from the prompt's first 2 seconds.
    2. 
          
  2. Add captions in the style named in the prompt (bold, centre-frame, word-by-word for stories).
    3. 
          
  3. Post at your audience's active hours and reply to early comments in the first hour.
    4. 
          
  4. Turn winning videos into a series using the same prompt family.
